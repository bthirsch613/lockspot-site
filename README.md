# lockspot-site

Public pages for the Lockspot iPhone app, served by GitHub Pages:

- https://bthirsch613.github.io/lockspot-site/ (home)
- https://bthirsch613.github.io/lockspot-site/privacy/ (privacy policy, linked from the app and App Store Connect)
- https://bthirsch613.github.io/lockspot-site/support/ (support URL for App Store Connect)

Plain HTML and one CSS file, no build step. The app code lives in a separate private repository.
